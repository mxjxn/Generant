A WORKBENCH FOR DAILY WORLDS

A small system with room to get strange.

Generant keeps sequencing, synthesis, modulation, and visual control in one place. Start with an empty patch, wire a few devices, then let patterns, envelopes, and OSC cues become the structure for a whole audiovisual piece.

THE SYSTEM

01 / 03
01

Tracker-first composition

Write notes, velocity, and indexed parameter events in a precise grid. Song mode turns patterns into an arrangement without hiding the details.

02

Modular CV

LFOs, envelopes, gates, scales, VCAs, and utility processors make motion a first-class musical signal.

03

Sound from code

SuperCollider synthdefs and a reusable device library keep the engine open for live tuning and new instruments.

AUDIO / VISUAL PROTOCOL

Let the music move the world.

The standalone OSC Score Bridge connects Generant to Blender for live controls, score cues, camera routes, and deterministic baking. Send a kick, a curve, or a marker like /song/part1.
